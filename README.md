# 🌱 GreenShop

Full-stack интернет-магазин микрозелени, разработанный на Next.js и TypeScript.

## О проекте

GreenShop — это интернет-магазин растений с регистрацией пользователей, административной панелью и системой управления товарами.

Проект разрабатывался с целью максимально приблизить функциональность к коммерческому продукту.

---

## Основные возможности

✅ Регистрация пользователей

✅ Авторизация (JWT)

✅ Каталог товаров

✅ Поиск товаров

✅ Фильтрация

✅ Корзина

✅ Оформление заказа

✅ Личный кабинет

✅ Административная панель

✅ CRUD товаров
